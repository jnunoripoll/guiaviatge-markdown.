2. [**Real Alcázar**](https://ca.wikipedia.org/wiki/Reales_Alc%C3%A1zares_de_Sevilla): Es el palacio real en uso _más antiguo de Europa_. Destacan sus salones y sus grandes jardines.

3. [**Plaza de España**](https://es.wikipedia.org/wiki/Plaza_de_Espa%C3%B1a_(Sevilla)): Una obra gigante en forma de círculo con bancos de azulejos para cada provincia de España. Está dentro del gran _Parque de María Luisa_.
